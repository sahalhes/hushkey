# ADR 001: Explicit local sanitization boundaries

Date: 2026-10-09. Status: accepted for MVP.

## Decision

Build a dependency-free local Node 22 TypeScript sanitizer, durable plaintext local mapping, CLI, explicit Codex stdin wrapper, and ChatGPT pre-paste companion. Restoration requires explicit local authorization and a restricted destination. Reject any requested proxy or global protection mode that cannot be enforced.

## Rationale

The documented `codex exec -` boundary permits deterministic local preprocessing with a synthetic capture test. Provider routing is configurable, but complete enforcement across tools and transports has not been verified. Hook prompt blocking is supported; prompt replacement and universal tool coverage are not established. ChatGPT plugins expose tools, UI, composer selections, and component-authored messages; reviewed documentation does not establish global local pre-send filtering.

## Consequences

Working narrow protection can ship without misrepresenting interception. Raw inputs and mappings stay local to Hushkey, but Codex can independently read other sources. Maps are sensitive plaintext. Users must manually paste companion output. Future work may add a pinned-protocol gateway or prompt-blocking hook after independent enforcement tests, without expanding claims ahead of evidence.
